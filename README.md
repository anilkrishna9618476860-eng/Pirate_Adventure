# 🏴‍☠️ Pirate Adventure - The Forbidden Cave

An immersive cinematic pirate adventure web game. Step into the shoes of Captain Thorne as you navigate ancient caves, face perilous trials, solve cryptic challenges, and uncover legendary treasures.

## 🌟 Features

- **Cinematic Presentation & Audio**: Atmospheric audio synthesis, ambient cave soundscapes, dynamic fog, and ember particle effects.
- **Interactive Multi-Level Storyline**:
  - **The Three Doors Trial**: Choose between the Crimson, Wooden, and Azure doors.
  - **The Raging River & Cavern Bridge**: Navigate deadly obstacles and hazardous pathways.
  - **Trial of Wit & Numbers**: Solve riddles, mathematical puzzles, and decipher ancient runes.
- **Visuals & Dynamic Animation**: Custom artwork, particle canvas engines, camera shake effects, and responsive design.
- **Zero External Dependencies**: Pure vanilla JavaScript, CSS3, and HTML5 (with MathJax for rendered mathematical notations).

## 🎮 How to Play

1. Clone or download the repository:
   ```bash
   git clone https://github.com/anilkrishna9618476860-eng/Pirate_Adventure.git
   ```
2. Open `index.html` in any modern web browser (Chrome, Edge, Firefox, Safari).
3. Toggle audio on/off using the HUD in the top-left corner.
4. Embark on the adventure and make choices to survive!
